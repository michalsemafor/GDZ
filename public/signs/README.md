# Priečinok pre vektorové grafiky značiek (.svg)

Sem nahrajte všetky vaše SVG súbory značiek.

### Pomenovanie:
Každý súbor musí byť pomenovaný presne podľa poľa `OZNACENIE` z Excel číselníka, napr.:
- `101.svg`
- `110-10.svg`
- `201.svg`
- `270.svg`
- `506-100.svg`

Grafiky sú vytvorené v mierke 1:1 vo Veľkosti 2 (VL 6.1).
Aplikácia automaticky škáluje rozmery pre Veľkosť 1 (0.7×) a Veľkosť 3 (1.25× / 1.4×).
