# Priečinok pre Excel číselník značiek

Sem nahrajte váš súbor:
`ciselnik_znaciek.xlsx`

### Požiadavky:
- Hárok (sheet): `data`
- Stĺpce:
  - `OZNACENIE` (napr. `101`, `110-10`, `270`, `506-100`)
  - `CISLO` (napr. `101`, `110`, `270`, `506`)
  - `TEXT` (oficiálny názov, napr. `Zákaz zastavenia`)
  - `ALT TEXT` (synonymá, napr. `Zatáčka, parkovanie, zákaz státia`)
